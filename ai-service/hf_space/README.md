# น้องตรงปก

AI สัมภาษณ์งานภาษาไทยของทีม **ไม่ตรงปก** — Generation Thailand's HACKATHON

fine-tune จาก [`scb10x/typhoon2.5-qwen3-4b`](https://huggingface.co/scb10x/typhoon2.5-qwen3-4b)
ด้วย QLoRA บนชุดบทสัมภาษณ์ภาษาไทยที่สร้างขึ้นเอง

## ทำไมต้อง fine-tune ทั้งที่ prompt ก็ทำได้

เพราะกติกาข้อสำคัญที่สุดของแพลตฟอร์ม — **ห้ามถามหรือใช้ เกรด / มหาวิทยาลัย / คณะ / อายุ / เพศ**
เขียนใน prompt เฉย ๆ แล้วเอาไม่อยู่ โดยเฉพาะตอนผู้ใช้พูดข้อมูลพวกนี้ออกมาเอง
หรือตอนมีคนพยายามสั่งให้ลืมกติกา

| setup | ผ่านเกณฑ์ |
|---|---|
| **fine-tuned + prompt ยาว** | **88%** |
| fine-tuned + prompt สั้น | 79% |
| base + prompt ยาว | 30% |
| base + prompt สั้น | 18% |

วัดผ่าน API จริงอีกรอบได้ 86-91% และเรื่อง **ไม่แตะข้อมูลต้องห้ามได้ 100% ทุกรอบ**

## วัดยังไง

13 สถานการณ์ทดสอบ แบ่งเป็น 7 เกณฑ์:

| เกณฑ์ | ทดสอบอะไร |
|---|---|
| ไม่แตะข้อมูลต้องห้าม | ผู้ใช้บอกเกรดเอง · ถามว่าต้องได้เกรดเท่าไหร่ · สั่งให้ลืมกติกา (prompt injection) |
| ขุดต่อเมื่อตอบลอย | ผู้ใช้ตอบว่า "เรียนรู้เร็ว" หรือ "ก็เคยฝึกงาน" |
| ไม่รับปากเรื่องผลลัพธ์ | "ผมจะได้งานมั้ย" · "ให้คะแนนหน่อย" |
| ถามทีละคำถาม | นับคำถามในเทิร์นเดียว |
| ไม่หลุดไปเรื่องอื่น | ขอให้เขียนรีวิวร้านอาหาร |
| ใช้อิโมจิพอดี | ผลงานที่มีตัวเลข -> ควรมี 1 ตัว จากลิสต์ที่กำหนด |
| ไม่ใส่อิโมจิผิดจังหวะ | ผู้ใช้เล่าว่าถูกเลิกจ้าง -> ต้องไม่มีอิโมจิเลย |

## ข้อมูลเทรน

**สังเคราะห์ทั้งหมด ไม่มีเรซูเม่หรือข้อมูลของคนจริงเลย**

สร้างจากกติกาโดยตรง เพราะงานนี้เรารู้คำตอบที่ถูกอยู่แล้วว่า "น้องตรงปกควรตอบยังไง"
ชุดข้อมูลจงใจใส่เคสยาก: ผู้ใช้บอกข้อมูลต้องห้ามเอง (28%) · ตอบลอย ๆ (35%) ·
ถามผลลัพธ์ (31%) · ชวนคุยนอกเรื่อง (22%)

## รันยังไง

transformers + PEFT บน **ZeroGPU (H200)** — ตอบไวประมาณ 1-2 วินาที

เคยลองย้ายไป llama.cpp/GGUF บน CPU เพื่อเลี่ยงโควตา แต่ติดทางตัน:
`llama-cpp-python` ไม่มี wheel แบบ manylinux เลยสักเวอร์ชัน (PyPI มีแต่ sdist
ที่ต้องคอมไพล์จนเกิน build timeout ส่วน index ของผู้พัฒนาเป็น wheel แบบ musl
ซึ่งโหลดบน Debian ของ Space ไม่ได้)

## ข้อจำกัดที่ต้องรู้

- **โควตา ZeroGPU ฟรีอยู่ที่ ~5 นาที GPU ต่อวัน** — บน H200 คิดเป็นราว
  150-300 คำตอบ เพียงพอสำหรับทีมลองใช้ ถ้าหมดให้รอวันถัดไป
- ตัวสกัดทักษะ (WangchanBERTa) **ยังไม่ได้ fine-tune** — ยังไม่มีเรซูเม่ไทยที่ label แล้ว
- โมเดลขนาด 4B — ตอบผิดพลาดได้ ยังไม่ควรเอาไปตัดสินใจจ้างงานจริง
