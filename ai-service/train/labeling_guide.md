# คู่มือ label ข้อมูล — อ่าน 5 นาที แล้วเริ่มได้เลย

> **ทำไมต้องมีอันนี้:** โมเดลเทรนแค่ 20 นาที แต่ข้อมูลใช้เวลา 2 สัปดาห์
> ถ้าไม่มีไฟล์นี้ แต่ละคน label ไม่เหมือนกัน โมเดลจะสับสนแล้ว F1 ตก
> **เป้า: คนละ 100 ประโยค ภายในสัปดาห์นี้** (ใช้เวลาราว 1 ชั่วโมง)

---

## เรากำลังสอนโมเดลให้ทำอะไร

ให้มันอ่านประโยคจากเรซูเม่แล้วชี้ว่า **ตรงไหนคือทักษะ** เหมือนเอาปากกาไฮไลต์ระบายทับ

```
ผมเขียน Python ดูแล stock ให้ร้านพ่อ
        ██████ ███████████
        KNOW      SKILL
```

---

## ป้ายมี 2 อันเท่านั้น

| ป้าย | คืออะไร | ตัวอย่าง |
|---|---|---|
| **KNOW** | ความรู้ เครื่องมือ เทคโนโลยี ภาษา — **สิ่งที่เป็นคำนาม** | `Python`, `Figma`, `Excel`, `กฎหมายแรงงาน`, `ภาษาจีน`, `React` |
| **SKILL** | การกระทำ สิ่งที่ลงมือทำ — **มักมีคำกริยา** | `ดูแล stock`, `เขียน unit test`, `จัดตารางเวร`, `แบ่งงานในทีม`, `ทำ OCR อ่านใบเสร็จ` |

**วิธีแยกง่าย ๆ:** ถ้าเติมคำว่า "เป็น/ได้" ข้างหน้าแล้วฟังขึ้น → KNOW
ถ้าเติมคำว่า "เคย" ข้างหน้าแล้วฟังขึ้น → SKILL

---

## กติกา 7 ข้อ (สำคัญที่สุด — อ่านให้ครบ)

### 1. ระบายให้สั้นที่สุดที่ยังได้ความหมาย
```
✅ ผมเคย[ดูแล stock]ให้ร้านพ่อมา 2 ปี
❌ ผมเคย[ดูแล stock ให้ร้านพ่อมา 2 ปี]      ← ยาวเกิน เอาบริบทมาด้วย
❌ ผมเคยดูแล[stock]ให้ร้านพ่อมา 2 ปี        ← สั้นเกิน ตัดกริยาทิ้ง ความหมายหาย
```

### 2. คำทับศัพท์อังกฤษ = ระบายรวมกับคำไทย ไม่ต้องแยก
```
✅ [ทำ presentation]ให้ลูกค้า
❌ ทำ[presentation]ให้ลูกค้า
```
> เรซูเม่ไทยเต็มไปด้วยแบบนี้ และมันคือจุดที่โมเดลอังกฤษแพ้เรา — label ให้ดี

### 3. ห้ามระบายคำลอย ๆ ที่ไม่มีหลักฐาน
```
❌ ผมเป็นคนที่[เรียนรู้เร็ว]
❌ [ทำงานเป็นทีมได้ดี]
❌ [มีความรับผิดชอบสูง]
```
> **นี่คือกติกาที่สำคัญที่สุด** ทั้งโปรเจกต์เราสร้างมาเพื่อแยกคำโม้ออกจากของจริง
> ถ้าเรา label คำโม้ว่าเป็นทักษะ = เราสอนโมเดลให้เชื่อคำโม้ = โปรเจกต์ไม่มีความหมาย
>
> แต่ถ้ามีหลักฐานต่อท้าย ให้ระบายเฉพาะส่วนที่เป็นหลักฐาน:
> `ผมเรียนรู้เร็ว [เขียน React เป็นภายใน 2 สัปดาห์]` ← ระบายแค่วงเล็บ

### 4. ชื่อวุฒิ ชื่อตำแหน่ง ชื่อบริษัท = ไม่ระบาย
```
❌ [นักศึกษาฝึกงาน]ที่[บริษัท ABC]
❌ จบ[ปริญญาตรี วิศวกรรมคอมพิวเตอร์]
```
> ตำแหน่งงานไม่ใช่ทักษะ และชื่อสถาบันคือสิ่งที่เราตั้งใจซ่อนอยู่แล้ว

### 5. ทักษะเดียวกันโผล่ 2 ที่ = ระบายทั้ง 2 ที่
โมเดลต้องเห็นว่ามันโผล่ได้หลายที่ ไม่ต้องกลัวซ้ำ

### 6. ไม่แน่ใจ = ข้ามไป อย่าเดา
ประโยคที่ตัดสินใจไม่ได้ให้ทิ้งไว้ก่อนแล้วเอามาถกกันในกลุ่ม
**ข้อมูลน้อยแต่สะอาด ดีกว่าข้อมูลเยอะแต่มั่ว**

### 7. ลบข้อมูลส่วนตัวออกก่อนเสมอ
ก่อนเอาเรซูเม่เข้าระบบ **ลบชื่อ เบอร์โทร อีเมล เลขบัตร ชื่อมหาลัย GPA ออกให้หมด**
แทนที่ด้วย `[ชื่อ]` `[เบอร์]` — เพื่อนที่ให้เรซูเม่มาไว้ใจเรา อย่าทำให้เขาเสียใจ

## ตัวอย่างเต็ม 6 ประโยค — ใช้เป็นมาตรฐาน

| ประโยค | ระบายอะไร |
|---|---|
| ผมเขียน **Python** ทำ **OCR อ่านใบเสร็จ** ให้ร้านพ่อ | `Python`=KNOW · `OCR อ่านใบเสร็จ`=SKILL |
| เป็นประธานชมรม **จัดค่าย 3 วันให้น้อง 80 คน** | `จัดค่าย 3 วันให้น้อง 80 คน`=SKILL |
| ใช้ **Figma** **ออกแบบ user flow** ของแอป | `Figma`=KNOW · `ออกแบบ user flow`=SKILL |
| มีความตั้งใจสูงและพร้อมเรียนรู้ | *(ไม่ระบายอะไรเลย — คำโม้ล้วน)* |
| **ดูแลเพจร้าน** ยอด follow ขึ้น 3 เท่าใน 6 เดือน | `ดูแลเพจร้าน`=SKILL |
| จบ ป.ตรี เกรด 3.45 | *(ไม่ระบายอะไรเลย — และต้องลบเกรดออกด้วย)* |

## ขั้นตอนทำจริง

1. เปิด Label Studio (เฟร้นจะส่งลิงก์ให้ในกลุ่ม)
2. เลือก project **"khontongpok-skill-ner"**
3. ลากเมาส์คลุมข้อความ → เลือกป้าย `SKILL` หรือ `KNOW`
4. กด **Submit** → มันจะเด้งประโยคถัดไปให้เอง
5. ครบ 100 ประโยคแล้วทักในกลุ่ม

### ถ้าอยากทำมือ (ไม่ใช้ Label Studio)
เขียนเป็นไฟล์ `.jsonl` บรรทัดละ 1 ประโยค — `start`/`end` นับเป็น**ตัวอักษร** เริ่มจาก 0

```json
{"text": "ผมเขียน Python ดูแล stock ให้ร้าน", "entities": [{"start": 8, "end": 14, "label": "KNOW"}, {"start": 15, "end": 25, "label": "SKILL"}]}
```

ส่งไฟล์มาที่ `data/labeled/` แล้วรัน `python train/prepare_dataset.py` เพื่อรวมและแบ่ง train/dev/test

---

## เช็คคุณภาพ (เฟร้นทำ)

หลังได้ครบ 800 ประโยค: สุ่ม 50 ประโยคให้ 2 คน label ซ้ำ แล้ววัด **inter-annotator agreement**
- ถ้า agreement > 0.75 → ใช้ได้
- ถ้าต่ำกว่านั้น → กติกายังไม่ชัด ต้องมาคุยกันใหม่ก่อนเทรน

> ตัวเลข agreement นี้เอาขึ้นสไลด์ได้ด้วย — มันบอกกรรมการว่าเราทำ dataset อย่างมีระเบียบ ไม่ใช่มั่ว
